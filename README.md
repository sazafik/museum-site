# Software and Computer Museum — сторінка «Екскурсії, експонати й курси»

Перша сторінка сайту музею комп'ютерної техніки. Вона знайомить відвідувачів з трьома рівноцінними напрямами — екскурсіями, експонатами й курсами — і веде до запису через одну форму.

Зроблено за технічним завданням музею (20.10.2026) і затвердженим макетом.

> **Статус:** сторінка зібрана й перевірена в браузері, але ще не готова до публікації. Ціни, фото, адреса, телефон і карта — заглушки. Форма поки не надсилає заявки нікуди (див. «Що ще не зроблено»).

## Що є на сторінці

| Блок | Що в ньому |
|---|---|
| Шапка | Логотип, навігація-якорі (Екскурсії · Експонати · Курси · Контакти), перемикач UA/EN, кнопка «Записатися»; на смартфоні — меню |
| Перший екран | Назва музею, слоган, три кнопки-переходи до розділів |
| **Екскурсії** | 3 картки: назва, тривалість, для кого, ціна, «Записатися» |
| **Експонати** | 6 карток (фото, назва, рік, підпис); сітка 3×2 на комп'ютері, 2 або 1 колонка на менших екранах; під сіткою — запис на оглядову екскурсію |
| **Курси** | 3 картки: назва, кількість занять, для кого, ціна, «Записатися» |
| Форма запису | Напрям, ім'я, телефон; перевірка полів і формату `+380…`; повідомлення про успіх або помилку |
| Контакти | Адреса, карта, години роботи, телефон |
| Підвал | Логотип, коротко контакти, перемикач мови, копірайт |

Кнопка «Записатися» в картці плавно прокручує сторінку до форми й підставляє обраний напрям.

**Стиль:** ретро-естетика комп'ютерів 80–90-х на фірмових синіх кольорах музею (`#233a7e`, `#1c4587`). Картки оформлено як «вікна» старих ОС. Піксельні шрифти використано лише в заголовках і кнопках, основний текст набрано читабельним шрифтом із кирилицею.

## Як переглянути

Сторінку треба відкривати через локальний сервер. Якщо відкрити `index.html` подвійним клацанням, стилі й скрипти не підвантажаться.

```bash
python -m http.server 8080
```

Потім відкрийте в браузері `http://localhost:8080`.

- `http://localhost:8080/?lang=en` — англійська версія.
- `http://localhost:8080/?fail=1` — стан форми «Не вдалося надіслати».
- Після змін у файлах натискайте **Ctrl+F5**, бо сервер не вимикає кешування.

## Структура проєкту

```
Сайт_музею/
├── index.html              сторінка: розмітка всіх блоків, український текст, SVG-піктограми
├── articles.html           список статей українською (згенеровано)
├── articles-en.html        список статей англійською (згенеровано)
├── articles/               статті: *.md — джерело, *.html — згенеровані сторінки
│   └── en/                 англійські переклади з тими самими назвами файлів
├── tools/build-articles.js збирає сторінки статей і articles.html з .md
├── assets/
│   ├── css/
│   │   ├── tokens.css      кольори, шрифти, відступи дизайн-системи (CSS-змінні; вручну не редагувати)
│   │   ├── fonts.css       підключення шрифтів (@font-face)
│   │   └── site.css        стилі блоків сторінки, лише на токенах
│   ├── fonts/              Oswald, Handjet, IBM Plex Mono (woff2) і ліцензії OFL
│   ├── ds/tokens.json      джерело токенів дизайн-системи
│   └── js/
│       ├── content.uk.js   українські тексти
│       ├── content.en.js   англійські тексти
│       ├── app.js          перемикач мови, меню, навігація, форма
│       └── booking.js      надсилання заявки (поки заглушка)
├── research-report.md      дослідження й джерела для статей
```

## Технічні рішення

- **Без фреймворків і збирача:** звичайні HTML, CSS і невеликий JavaScript. Сторінка читається навіть із вимкненим JS.
- **Стилі окремо від розмітки:** усі кольори, шрифти й відступи беруться з `tokens.css`, а `site.css` не вводить нових значень.
- **Адаптивність:** від 1280 px — 3 колонки, 768–1279 px — 2, до 767 px — 1 колонка й мобільне меню.
- **Дві мови:** UA/EN без перезавантаження сторінки. Вибір мови запам'ятовується.
- **Доступність (орієнтир WCAG 2.1 AA):** основний текст від 16 px, зони натискання від 44 px, видима рамка фокусу, керування з клавіатури, «Перейти до основного вмісту». Якщо в системі ввімкнено зменшення руху, анімації вимикаються.
- **Шрифти лежать локально,** тож сторінка не робить зовнішніх запитів. Ліцензії SIL OFL 1.1 треба публікувати разом зі шрифтами.

## Як змінювати тексти

Український текст записаний у двох місцях: в `index.html` (щоб сторінка працювала без JS) і в `assets/js/content.uk.js` (щоб повертатися з EN на UA). Змінюючи текст, оновіть обидва файли. Англійський текст лежить лише в `content.en.js`.

## Як оновити статті

Сторінки статей і списки `articles.html` / `articles-en.html` збираються з Markdown-файлів: українські лежать у `articles/`, англійські — в `articles/en/` під тими самими назвами (назва має починатися з номера, наприклад `07-....md`). Шапку, підвал і піктограми скрипт бере з `index.html`, англійські підписи — з `content.en.js`. Після зміни статті, шапки чи словників запустіть із кореня сайту:

```bash
node tools/build-articles.js
```

Згенеровані `.html` вручну не редагуйте. Кожна мова — окрема сторінка: перемикач UA/EN на сторінці статті переходить на ту саму статтю іншою мовою. Якщо для статті ще немає перекладу, скрипт про це попередить, а перемикач поведе на головну англійською.

## Що ще не зроблено

1. **Надсилання заявок.** `booking.js` — заглушка: імітує успішне надсилання через 1,2 с. Коли музей вирішить, хто й як отримуватиме заявки, треба зробити серверну частину й замінити заглушку на запит до неї. Без цього запускати сайт не можна.
2. **Справжні матеріали:** фото, описи, ціни, розклад, адреса, години роботи, телефон, логотип у SVG.
3. **Рішення від музею:** згода на обробку персональних даних, вид карти, переклад англійською, зв'язок зі сторінкою реєстрації на події.
